# results/

Benchmark output. Most of this directory is **gitignored** —
only the generated report and the figures may be committed
as part of a release tag.

## Layout

* `runs/`
  * `results.parquet` — *gitignored* — the structured result
    store, one row per `(config_id, file_id)` aggregate.
  * `results.csv` — *gitignored* — human-readable mirror.
  * `results.json` — *gitignored* — sidecar with the nested
    `BenchmarkRun` objects preserved (used by the dashboard).
  * `telemetry/` — *gitignored* — one `tegrastats` log per run
    ID.
* `reports/`
  * `benchmark_report.md` — generated by
    `scripts/build_report.py`. May be committed.
* `figures/`
  * `*.png` — generated plots from the report. May be
    committed.

## Reproducing a report

```bash
make report
```

This rebuilds `results/reports/benchmark_report.md` from
`results/runs/results.parquet`.
