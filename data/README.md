# data/

The Polish evaluation set used by the benchmark.

## Layout

* `manifests/`
  * `benchmark_manifest.jsonl` — frozen JSONL, one row per clip.
  * `manifest_version.txt` — one-line human-readable version tag.
  * `manifest_checksum.txt` — SHA-256 of the manifest.
* `raw/` — *gitignored* — the original Common Voice download, if
  you choose to keep a local copy.
* `prepared/` — *gitignored* — the 16 kHz mono WAVs that the
  benchmark reads. Generated by
  `data/scripts/prepare_polish_eval.py`.
* `scripts/`
  * `prepare_polish_eval.py` — CLI for downloading and freezing
    the Polish subset.

## Reproducing the data

```bash
# One-time:
python -m data.scripts.prepare_polish_eval \
  --output-audio data/prepared/audio \
  --output-manifest data/manifests/benchmark_manifest.jsonl \
  --max-clips 20
```

This downloads a slice of Common Voice Polish v11.0, normalizes
each clip to 16 kHz mono WAV, and writes the manifest. The
audio files and the manifest are *not* committed to git.
